Question
A very special island is inhabited only by knights and knaves. Knights always tell the truth, and knaves always lie. You meet 3 inhabitants: Michael, Zoey, and Ethan. Michael said, "Ethan is a knight if and only if Michael is a knight." Zoey said, "Zoey is a knight or Ethan is a knight." Ethan said, "Michael is a knave if and only if Zoey is a knave." So who is a knight and who is a knave?
Rules

* A knight's statement is always TRUE.
* A knave's statement is always FALSE.
* If a person's type does not match the truth of their statement, that guess is impossible.

What each statement means

* Michael's statement means: "Michael and Ethan are the same type." It is TRUE if they are the same type. It is FALSE if they are different types.
* Zoey's statement means: "At least one of Zoey and Ethan is a knight." It is TRUE if one of them is a knight or if both are knights. It is FALSE only if both are knaves.
* Ethan's statement means: "Michael and Zoey are the same type." It is TRUE if they are the same type. It is FALSE if they are different types. It does NOT say that Michael is a knave. It does not talk about Ethan.
